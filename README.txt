ROADTRIP PROJECT STRUCTURE

This archive contains the initial empty folder and file structure.
No application code or database credentials have been added yet.

Setup:
1. Extract the roadtrip folder.
2. Move it to C:\\xampp\\htdocs\\roadtrip
3. Open the folder in VS Code.
4. Start Apache and your chosen MySQL/MariaDB server in XAMPP.
5. Visit http://localhost/roadtrip/ after we add the initial PHP code.

Frontend: assets/css/style.css and assets/js/script.js, plus the page templates.
Backend: config/, includes/, and actions/.
Role pages: admin/, staff/, and traveler/.
